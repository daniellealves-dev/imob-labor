# 🏡 Imob Tejo

Landing page imobiliária fictícia inspirada no mercado português, desenvolvida como projeto de portfólio com **HTML5, CSS3 e JavaScript**.

O projeto apresenta imóveis para venda, arrendamento e alojamento de curta duração, além de informações sobre serviços e contactos.

🌐 **[Acesse o projeto online](https://daniellealves-dev.github.io/imob-labor/)**

---

## 📌 Sobre o projeto

A **Imob Tejo** foi desenvolvida como uma proposta de website institucional para uma imobiliária fictícia atuante em Portugal.

A ideia foi criar uma interface moderna, organizada e responsiva para apresentar diferentes imóveis e proporcionar uma experiência de navegação simples ao usuário.

Além da construção visual da página, o projeto teve como foco a prática de **JavaScript aplicado ao DOM**, criando interações dinâmicas para a apresentação dos detalhes de cada imóvel.

## ✨ Funcionalidades

### 🏠 Catálogo de imóveis

A página apresenta seis imóveis localizados em diferentes regiões de Portugal:

- Apartamento em Óbidos
- Moradia em Viseu
- Apartamento em Coimbra
- Moradia em Oliveira de Frades – Viseu
- Apartamento no Porto
- Casa em Aveiro

Cada imóvel apresenta informações como:

- Localização
- Tipologia
- Preço
- Área
- Número de quartos
- Casas de banho
- Garagem
- Certificação energética
- Estado de mobiliário

### 🔎 Modal de detalhes

Ao clicar em **"Ver detalhes"**, o usuário pode visualizar informações adicionais sobre o imóvel selecionado sem sair da página.

Os dados dos imóveis são organizados em objetos JavaScript e utilizados dinamicamente para preencher o conteúdo do modal.

Essa abordagem evita a criação de um modal independente para cada imóvel e permite reutilizar a mesma estrutura para diferentes conteúdos.

### ⌨️ Interações com JavaScript

O projeto utiliza JavaScript para:

- Selecionar elementos do DOM
- Capturar eventos de clique
- Identificar o imóvel selecionado
- Atualizar dinamicamente textos e imagens
- Exibir e ocultar o modal
- Fechar o modal através do botão de fechamento
- Fechar o modal utilizando a tecla `Escape`

### 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela.

Foram utilizados:

- CSS Media Queries
- CSS Grid
- Flexbox
- Elemento `<picture>` para utilização de imagens diferentes conforme a largura da tela
- Ajustes específicos para dispositivos menores

A responsividade foi testada em diferentes dimensões de dispositivos móveis durante o desenvolvimento.
